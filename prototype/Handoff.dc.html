Hearth · Flutter handoff

From prototype to Material 3 widgets

Everything in the prototype uses patterns Flutter has natively: Column/Row with gaps, NavigationBar, modal bottom sheets, SnackBar with action. No hover, no browser-only CSS.

// Sheets: showModalBottomSheet(useSafeArea, showDragHandle)

Bottom bar shows on the three tab roots only. Chat, editor and settings are pushed full-screen so the reading area is clean. Android back always pops one level; on a tab root it goes to Characters, then exits. Chat ↔ Story is a state toggle on the same route, never a new route, so context and scroll position carry over.

5 · Interaction states — a reply's life

idle→ send thinking→ first token streaming→ done stopped error: limit · busy · offline
thinking“Vesper is writing…” with three pulsing dots. Composer Send becomes Stop. After 20 s add “Still working — this model is slow right now.”
streamingAppend chunks to the message; caret at the end. Auto-follow only if the list is at the bottom; otherwise show “New reply below”.
stoppedKeep partial text with an ellipsis; actions appear (Rewrite, Edit). Nothing is lost.
rewriteAdds a new alt to the same message and streams into it; ‹ › moves between alts. The next user message branches from the visible alt.
errorInlineNotice in the list where the reply would be. Limit/busy → “Switch model” (primary) re-sends automatically; offline → queue and “Try again”.

Also design for: pressed (InkWell splash on surfaceRaised), focused (2dp primaryInk outline), disabled (surface fill, textSubtle label + a reason nearby), selected (chips and segments).

6 · Responsive behaviour

  • Compact (<600dp): as designed; 20dp gutters, 2-column character grid.
  • Medium (600–839): 3-column grid; NavigationRail replaces the bottom bar.
  • Expanded (≥840): Chats becomes list-detail; chat and story text capped at 640dp wide.
  • Keyboard: resizeToAvoidBottomInset on; the reversed list keeps the latest message visible above the composer.
  • Landscape phone: hide the story header on scroll; composer stays one line until focused.

7 · Accessibility

  • All tap targets ≥48dp (MaterialTapTargetSize.padded); inline message actions ≥44dp tall with labels.
  • Every text/background pair ≥4.5:1; accent burgundy is never used for text.
  • Support text scale to 200%: no fixed-height text containers; cards grow.
  • TalkBack: announce a reply once when it finishes (SemanticsService.announce), not per chunk; “Vesper is writing” is a live region.
  • Icon buttons have tooltips + semantic labels; toggles use Switch semantics; selected chips expose selected state.
  • Honour “Remove animations” (MediaQuery.disableAnimations): show replies whole instead of streaming.
