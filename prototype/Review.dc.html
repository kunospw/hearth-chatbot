Hearth · UX review

Six journeys, counted tap by tap

Counted in the prototype from a cold open. Typing is not a tap. Targets: 1 tap to resume, 2–3 taps to start a new chat.

JourneyPath in the prototypeTapsWhat we cut or simplifiedWatch-outs → fix
A · Pick a character and start chatting Character card → Start new chat → type → send 2 No persona, model or scenario picker before chatting — sensible defaults apply. The greeting is already on screen when the chat opens. “Start new chat” next to an existing chat could fork stories by accident → details screen shows a Resume “…” link right above it.
B · Resume the last conversation Continue story card at the top of home 1 The whole card is the button, with title and last line so you know where you left off. Two more recent chats sit right below it. Chats tab is a second route (2 taps) with search and pins. The chat opens scrolled to the newest message.
C · Create a character, save, chat New character → type a name → Save & start chat 2 Only the name is required. Avatar defaults to a colour and initial; blank greeting gets a written default. Seven advanced fields sit behind one “More details”. Save and chat is one button, not two steps. Users may think every field is required → helper copy says “everything else is optional” and the disabled button explains why. Fixed: leaving with changes now asks Save draft / Keep editing / Discard, and Back from the new chat returns home, not to the editor.
D · Switch Chat → Story mode Story pill in the chat header (and back with Chat) 1 Same conversation, same messages, re-rendered as prose. Fixed: you land on the same message you were reading, and each chat remembers its own mode when you come back. “Aa” in Story mode is a convention, not a word → it has an accessible name; if testing shows hesitation, swap to a “Text” label.
E · View or edit a saved memory In chat: ⋯ → Memories in this world → tap memory → edit → Save 4 The chat shortcut opens memories already filtered to the right universe, skipping Library → tab → filter (would be 5–6). Pin toggles in place, no edit screen. Users may not know memories exist → the first time a character recalls one, show a quiet “Remembered: …” chip that links here. Next: Remember this in the message actions.
F · Change model after a rate limit Inline error → Switch model → pick Lumen (reply starts automatically) 2 No trip to Settings, no retyping: the unanswered message is kept and re-sent. Unavailable models are greyed out and say why (busy, or limit + reset time). Free usage must never feel unlimited → AI settings show “2 of 30 free replies left today” before the wall, and the limit copy names the reset time.
G · See why a relationship changed Tap “Trust grew a little · Why?” under your message → the journal opens with that moment expanded 1 No HUD in the chat. Notes use words, never numbers, and can be hidden. Undo and Adjust live in the journal, not mid-scene. Users may expect a “love meter” → attraction is gated by relationship type, and behaviour lines say plainly how the character will act.

What's working

  • One primary action per screen, always the burgundy button at the bottom.
  • Chat header holds just back, who you're talking to, Story and ⋯.
  • Technical words only appear inside AI settings → Advanced.
  • Streaming never yanks you down while you're reading back; a “New reply below” pill appears instead.

Fixed during review

  • Message actions were hidden behind long-press (undiscoverable) → latest reply shows them; older ones use a visible ⋯.
  • “Regenerate” → “Rewrite”, with version arrows “2 of 3”.
  • Delete chat now asks first; deleting a memory gives Undo.
  • Empty Story composer means “Continue”, so readers can keep going without typing.

Refinement pass, verified

  • Each journey was traced through the prototype's logic, and four bugs were fixed along the way.
  • All inline targets were raised to ≥44 px; primary ones are 48–52.
  • Portraits fall back to the initial; empty, loading and offline home states were added.
  • Composer focus jumps to the latest message; Enter makes a new line.

Test next with real users

  • Do people understand Universes without the word “lorebook”?
  • Is “Rewrite” clearer than “Try again” or “Another version”?
  • Personas: should the active one show in the chat header?
  • How long can AI replies get before Story mode becomes the default?
